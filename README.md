# ✈️ Travelgram

Página de perfil para compartilhamento de viagens, com informações da viajante e uma galeria de registros fotográficos.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid

## 🎨 Layout

O design simula uma rede social de viagens, combinando barra de navegação, perfil do usuário, dados de viagem e galeria de imagens.

## 🧩 Seções do projeto

- **Navegação**: Logomarca, busca e links de exploração
- **Perfil**: Biografia e informações da viajante
- **Galeria**: Registros fotográficos das viagens
- **Rodapé**: Links complementares da plataforma

## 📖 Aprendizados

Durante o desenvolvimento deste projeto, pratiquei:

- Criação de layouts responsivos para páginas de perfil
- Uso de Flexbox e Grid para organizar conteúdos
- Modularização de estilos CSS por seção
- Construção de galerias de imagens com HTML e CSS
